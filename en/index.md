# K230 RTOS Only SDK Documentation

## K230 Introduction

The latest generation AIoT SoC K230 chip in Canaan Technology's Kendryte® series of AIoT chips adopts a brand-new multi-core heterogeneous unit accelerated computing architecture, integrating 2 RISC-V high-efficiency computing cores and a built-in next-generation KPU (Knowledge Process Unit) intelligent computing unit. It provides multi-precision AI computing power and broadly supports general-purpose AI computing frameworks, with the utilization rate of some typical networks exceeding 70%.

This chip also supports a rich set of peripheral interfaces and integrates multiple dedicated hardware acceleration units such as 2D and 2.5D, capable of accelerating various types of tasks including image, video, audio, and AI. It features low latency, high performance, low power consumption, and fast boot-up capabilities.
